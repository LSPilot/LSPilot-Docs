主题、动态背景、模糊与底栏样式都在这里调整，改动即时生效，可以边看边试。

## 主题

| 配置项 | 说明 |
| --- | --- |
| 深浅色模式 | 深色 / 浅色 / 跟随系统 |
| 主题颜色 | 自定义主题色，可在调色板中挑选或精确指定 |
| 配色风格 | 内置多种配色方案（如蓝灰、深青、天蓝、橄榄、靛蓝等） |
| Monet 主题 | 支持设备上启用 Material You 动态取色，从壁纸提取配色 |

## 界面效果

| 配置项 | 说明 |
| --- | --- |
| 动态背景 | GLSL 着色器动画背景，亮色 / 暗色自动适配 |
| 启用模糊 | 在界面中启用背景模糊（毛玻璃） |
| 液态玻璃效果 | 更强调折射与高光的玻璃质感效果 |
| 页面缩放 | 80% – 120% 自由调节整体页面比例 |

## 底栏

| 配置项 | 说明 |
| --- | --- |
| 底栏样式 | 图标 + 文字 / 仅图标 |
| 悬浮底栏 | 底栏脱离屏幕边缘悬浮显示 |
| 悬浮底栏玻璃模糊 | 为悬浮底栏启用模糊背景 |

## 悬浮窗相关

性能悬浮窗与 UI 检视触发器的外观是独立配置的：悬浮窗默认停靠方位、指标排列方向与样式、主题强调色、背景不透明度、文字尺寸、预警与危险阈值、刷新间隔。详见[性能观测](/guide/observe/performance)。

## 实验性功能

**设置 → 关于 → 实验性功能**用于开关仍处于实验阶段的能力。进入方式有两种：

- 在**首页连点 5 次激活状态卡片**（相邻两次间隔不超过 0.5 秒），会切换实验模式的开关并弹出提示；
- 实验模式开启后，**关于**页会出现「实验性功能」入口。

目前其中的主要开关是**性能悬浮窗**，详见[性能观测](/guide/observe/performance)。

## 语言与字号

- 界面字号跟随系统字体缩放；
- 界面语言跟随系统区域设置（内置简体中文、繁体中文与英文资源）。
