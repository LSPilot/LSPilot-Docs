LSPilot 的功能按**使用场景**分成五个域。每个域下面 2–3 页，覆盖从配置到实际操作的全部内容。

| 域 | 解决什么问题 | 包含 |
| --- | --- | --- |
| **AI** | 让 AI 帮我定位、分析、写脚本 | 对话与模型、工具调用与工作过程 |
| **项目** | 管理目标应用、插件与代码 | 应用与作用域、插件与日志、代码编辑器 |
| **观测** | 看清运行时到底发生了什么 | UI 检视、性能观测 |
| **环境** | 设备上的工具与数据 | 终端、内置浏览器、存储空间 |
| **定制** | 把界面调成顺手的样子 | 外观与界面、Skills 与 Prompt |
