这里集中管理 LSPilot 占用的空间：终端环境、聊天记录与各类缓存，并展示设备剩余容量。

## 概览

**设置 → 存储空间**展示设备存储空间与 LSPilot 各类数据的占用：

| 分类 | 内容 |
| --- | --- |
| 终端环境 | Ubuntu rootfs 与已安装的软件包 |
| 聊天记录 | AI 对话历史（会话与消息数据库） |
| APK 缓存 | AI 调用时生成的 APK 副本 |
| 编辑器缓存 | 代码编辑器的索引与语法缓存 |
| 其他缓存 | 图片、临时文件等 |

每一项都可以单独清理，界面会显示「可用 / 共」的容量对比。

## 清理注意事项

<Callout type="warn">
  清理操作不可撤销。
</Callout>

- **终端环境**：清除后下次启动终端会重新下载 Linux 环境，需要联网。
- **聊天记录**：清除后所有历史会话丢失。
- **APK 缓存**：清除后 AI 下次分析会重新生成副本，首次调用会变慢。
- **编辑器缓存**：清除后重新打开文件时可能短暂变慢，不影响内容。

## 与插件目录的关系

插件本身保存在 `Android/media/<目标应用包名>/LSPilot/Plugin/` 下，属于**目标应用的媒体目录**，不在存储空间页的管理范围内。删除插件请在**应用详情 → 插件**中操作，或直接在文件管理器中删除对应目录。
