内置终端提供一套 Ubuntu 环境，可以在设备上直接跑命令、装工具、验证脚本；AI 的 `run_command` 用的就是同一套环境。

## 概述

LSPilot 内置了基于 Xed 的终端界面与一套 Ubuntu 环境，可以直接在设备上执行 Linux 命令、安装软件包、跑脚本，与逆向分析流程待在同一个应用里。

AI 的 `run_command` 工具与终端界面**共用同一套环境**，因此在终端里准备的东西（安装的工具、下载的文件）AI 也能直接使用。

## 环境

| 项目 | 说明 |
| --- | --- |
| 发行版 | Ubuntu 24.04 base |
| 安装方式 | 首次使用终端或首次调用 `run_command` 时自动下载并解压 rootfs |
| 工作目录 | 终端启动后位于 `/root`；AI 执行 `run_command` 时以 root 身份运行，起始目录为 `/home` |
| 网络 | 需要联网完成首次环境下载 |

<Callout type="info">
  首次使用需要下载 rootfs，耗时取决于网络状况。下载完成后环境会保留，后续启动直接可用。
</Callout>

## 运行模式

| 模式 | 说明 |
| --- | --- |
| 免 Root 模式（proot） | 通过 proot 用户态模拟运行，**不需要 Root**，兼容性最好 |
| chroot 模式 | 需要 Root，直接使用内核 chroot，性能更好 |

模式在终端设置中选择。AI 调用 `run_command` 时默认跟随该设置，也可以在单次调用中通过 `mode` 参数覆盖。

## 终端功能

- 多会话与虚拟按键（方向键、Ctrl、Tab、Esc 等），方便在触屏上操作；
- 终端设置：字号、配色、光标样式、模式切换等；
- 内置包管理器辅助：`apt`、`pip` / `pipx`、`npm` 等常用工具可直接使用；
- 与代码编辑器互通，可以从编辑器直接打开终端。

## 与 AI 的配合

典型用法：

```text
帮我在终端里看看 /data/local/tmp 下有什么文件，然后用 apktool 解一下这个包。
```

AI 会调用 `run_command` 执行命令，输出会逐行流式回传到对话中。需要注意：

- 命令有默认超时（30 秒），可以通过 `timeout` 参数调整；
- 长输出会被截断（超过 8000 字符），必要时让 AI 分页读取或把结果写到文件再读。

## 清理环境

在**设置 → 存储空间 → 终端环境**中可以清除 Linux 环境释放空间。

<Callout type="warn">
  清除后下次启动终端会重新下载环境，此操作不可撤销。
</Callout>
