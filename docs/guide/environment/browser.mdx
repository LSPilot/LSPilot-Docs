分析过程中经常要查文档、下载样本。内置浏览器让你不必离开 LSPilot。

## 用途

分析过程中经常需要查文档、看接口说明、下载样本或对照在线资料。内置浏览器让你不必离开 LSPilot：

- 打开网页并正常浏览；
- 下载文件并统一管理；
- 与 AI 的 `web_fetch` / `web_search` 工具配合：AI 负责检索与摘要，你在浏览器里看原文。

## 功能

| 功能 | 说明 |
| --- | --- |
| 网页浏览 | 基于 WebView，支持前进 / 后退 / 刷新与手势操作 |
| 下载管理 | 独立的下载列表页面，查看进度、打开或删除已下载文件 |
| Blob 下载 | 支持页面内通过 Blob 生成的文件下载 |
| 浏览器设置 | 主页、搜索引擎、User-Agent、下载目录等偏好设置 |

## 入口

从应用内的链接或设置中的相关入口进入；下载列表是独立页面，可从浏览器界面进入。
