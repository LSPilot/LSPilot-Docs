代码编辑器用来就地查看与修改插件脚本和应用文件，并用 Hook 模板把「类名 + 方法名 + 参数」这类样板代码自动生成。

## 入口

- **应用详情 → 插件 → 编辑**：编辑某个插件的 `main.java`。
- **应用详情 → 分析 → 代码编辑器**：以插件目录为根打开文件浏览器，可查看与编辑目录中的任意文件。

## 编辑器能力

| 能力 | 说明 |
| --- | --- |
| 多标签 | 同时打开多个文件，标签页可关闭当前 / 关闭其他 / 关闭全部 |
| 语法高亮 | 基于 TextMate 语法，覆盖 Java、Kotlin、JSON、XML、Smali 等常见格式 |
| 代码补全 | 编辑时给出补全建议 |
| 自动换行 | 可切换 |
| 只读模式 | 防止误改 |
| 跳转到行 | 直接定位到指定行 |
| 行操作 | 复制行、剪切行、删除行、清空行、转为大写 / 小写、增加 / 减少缩进、切换注释 |
| 撤销 / 重做 | 标准编辑历史 |
| 底部快捷栏 | 可自定义显示哪些快捷操作与符号 |
| 终端入口 | 在编辑器内直接打开终端，方便验证命令 |

## 文件侧边栏

- 树形展示插件目录，支持新建文件与新建文件夹；
- 支持多选，可批量删除；
- 顶部显示当前目录下的文件数与文件夹数。

<Callout type="warn">
  侧边栏中的删除操作不可撤销。删除插件目录中的 `main.java` 或 `info.prop` 会让插件不再被识别。
</Callout>

## Hook 模板

写 Hook 代码时最繁琐的是类名、方法名与参数签名。模板功能把这一步自动化：

1. 在编辑器中打开**模板**面板；
2. 选择「**粘贴签名**」：把 jadx 或 Smali 中的方法签名粘贴进来，LSPilot 会解析出类名、方法名、参数个数并实时预览；
3. 或选择「**手动输入**」：自己填写类名、方法名、参数类型与返回值类型；
4. 确认后把模板代码插入到光标位置。

模板首次启动时是空列表，需要自己添加。模板本身可增删改，支持以下占位符（写入模板代码时使用）：

| 占位符 | 含义 |
| --- | --- |
| `{className}` | 原始类名，形如 `Lcom/foo/Bar;` |
| `{classDot}` | 点分类名，形如 `com.foo.Bar` |
| `{methodName}` | 方法名 |
| `{params}` | 参数类型列表（Java 写法，逗号分隔） |
| `{paramsJava}` | 形如 `, java.lang.String::class.java` 的参数片段 |
| `{returnType}` | 返回值类型 |

## 符号面板

可以把常用代码片段（例如 `hookMethodAfter` 骨架、`log` 调用）保存为**符号**，一键插入。符号同样支持占位符：表示美元符号、设置插入后的开始选中位置、设置结束选中位置、表示当前选中的文本。

## 保存与生效

编辑器保存后写入的是磁盘上的脚本文件。要让修改生效：

- **插件脚本**：强制停止并重启目标应用。
- **其它文件**：视用途而定，例如日志文件只读，配置文件可能需要重启应用。
