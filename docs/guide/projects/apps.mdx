LSPilot 以**应用**为单位组织一切：插件按应用分区存放，AI 会话绑定到某个应用，注入范围也按应用控制。

## 项目页

项目页分为两个标签：

| 标签 | 内容 |
| --- | --- |
| **应用** | 设备上已安装的应用 |
| **自定义** | 与已安装应用无关的项目：手动导入的 APK、自建分组 |

### 应用列表

| 操作 | 说明 |
| --- | --- |
| 搜索 | 按应用名或包名过滤 |
| 排序 | 应用名 / 包名 / 安装时间 / 更新时间，可切换正序倒序 |
| 隐藏系统应用 | 过滤掉系统自带应用 |
| 右侧开关 | 把该应用加入或移出 LSPilot 的注入范围 |

打开开关会写入 `Android/media/<包名>/LSPilot/.enabled` 标记。**首次启用需要强制停止并重新打开目标应用**，注入才会发生。

### 自定义项目

- **导入 APK 安装包**：从文件中选择 APK，解析包名与图标后作为独立项目，便于分析尚未安装或不便安装的样本。
- **创建项目分组**：手动命名一个分组并填写描述，把相关目标集中管理。

## 应用详情页

### 分析操作

| 操作 | 说明 |
| --- | --- |
| 启动软件 | 启动目标应用 |
| 重启软件 | 强制停止后重新启动（需要 Root） |
| 强制停止 | 结束目标应用进程（需要 Root） |
| 动态配置 | 查看连接状态，并为该应用打开「实时性能面板」或「可视化布局」 |
| 重连 | 重新建立与宿主进程的跨进程桥连接 |

### 注入进程

| 模式 | 说明 |
| --- | --- |
| 主进程 | 只注入目标应用的主进程，最省资源 |
| 子进程 | 只注入子进程（如独立 `:remote` 进程） |
| 所有进程 | 注入全部进程，适合多进程应用，开销最大 |

配置保存在 `Android/media/<包名>/LSPilot/.process_mode`。

### 动态配置里的两个开关

| 开关 | 作用 |
| --- | --- |
| 实时性能面板 | 为宿主注入性能悬浮窗，见[性能观测](/guide/observe/performance) |
| 可视化布局 | 为宿主注入 UI 检视触发器，见[UI 检视](/guide/observe/inspector) |

两个开关的状态按项目（包名）独立记录，宿主未连接时不可用。
