AI 不是「猜」出类名和方法的，它靠**工具调用**（function calling）去实际检索与反编译。这一页说明工具是怎么被调用的、怎么开关、输出怎么看。完整的工具清单见[内置工具清单](/ref/tools)。

## 一次工具调用发生了什么

<Steps>
  <Step>你发出一条消息，LSPilot 把**可用工具定义**随请求一起发给模型。</Step>
  <Step>模型决定调用某个工具，返回工具名与参数（而不是直接回答）。</Step>
  <Step>LSPilot 执行该工具：内置工具与外部 MCP 工具在独立 `:mcp` 进程执行，MCP 插件工具在 LSPilot 进程执行。</Step>
  <Step>输出逐行回传，作为工具结果追加到对话中，模型据此继续下一步或给出结论。</Step>
  <Step>循环直到模型不再调用工具，输出最终回答。</Step>
</Steps>

整个过程折叠在对话的**工作过程**卡片里，展开可以看到每一步的工具、参数与结果。

## 三类工具

| 类型 | 函数名形态 | 执行位置 | 来源 |
| --- | --- | --- | --- |
| 内置工具 | 无前缀，如 `decompile_class` | `:mcp` 进程 | LSPilot 自带 |
| 外部 MCP 工具 | `mcp__<服务器>__<工具>` | `:mcp` 进程 | 你接入的远程 MCP 服务器 |
| MCP 插件工具 | `plugin__<插件>__<工具>` | LSPilot 进程 | 你写的 MCP 插件 |

## 开启与关闭

**设置 → 功能拓展 → MCP 拓展 → 内置** 里是两级开关：

1. **分组总开关**：分类卡片右侧的开关。分组**默认关闭**，需要先打开。
2. **单个工具开关**：点进分类后逐项开关，右上角支持批量开启 / 关闭。

被关闭的工具不会出现在模型的工具定义里。外部 MCP 工具与 MCP 插件工具分别在[接入 MCP 服务器](/plugin/mcp/servers)与[编写 MCP 插件](/plugin/mcp/plugin)中开关。

<Callout type="info">
  **极简模式**会忽略以上开关，只保留终端工具 `run_command`，并且不注入 MCP 工具与技能。适合轻量问答或排查工具干扰。
</Callout>

## 试运行

工具列表每行的**运行**按钮可以绕过 AI 直接执行：

- 无参数工具立即执行；
- 有参数工具弹出参数表单（必填项带星号，枚举给出可选项）；
- 结果面板与对话中的工具输出使用同一个查看器。

排查「到底是工具的问题还是模型的问题」时很有用。

## 查看输出

工具输出查看器支持行号与选区复制，并按工具类型套用语法高亮：

| 工具 | 高亮 |
| --- | --- |
| `decompile_class` / `decompile_method` / `read_plugin` / `write_plugin` / `file_read` | Java |
| `get_class_smali` / `get_method_smali` | Smali |
| `run_command` | 日志 |
| `edit_plugin` / `file_edit` | diff |

## 执行位置与隔离

内置工具与外部 MCP 工具运行在独立的 `:mcp` 进程，这样做的原因：

- **内存隔离**：DexKit 的全量索引等重型内存开销不计入主进程堆；
- **崩溃隔离**：工具或 MCP 连接崩溃只影响 `:mcp` 进程，界面不受影响，下次调用会自动重新绑定。

## 懒加载与首次耗时

工具按需要的资源分四级懒加载，第一次调用某类工具时会做一次准备：

| 层级 | 准备动作 | 典型工具 |
| --- | --- | --- |
| 元数据 | 读取应用信息 | 插件管理、`read_manifest`、UI 检视类 |
| APK | 复制目标 APK 到缓存 | `list_layouts`、`list_resources` |
| 反编译 | 建立轻量类索引 | `decompile_class`、`get_class_smali` |
| DEX | 初始化 DexKit 全量索引 | 搜索与查找类工具 |

因此**第一次**反编译或搜索会明显慢于后续调用。会话结束、请求异常或页面销毁时会释放索引。

## 输出长度与失败

- 工具输出超过 **8000 字符**会被截断并提示剩余长度，可以让 AI 分页读取或先写入文件；
- 工具执行失败会以 `// Error ...` 文本形式返回，模型能看到错误并自行重试或换策略；
- 参数 JSON 会被自动清洗（去掉代码围栏、零宽字符、尾随逗号）。
