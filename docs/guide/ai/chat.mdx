对话页是 LSPilot 的主界面：你描述需求，它调用工具去检索、反编译、生成脚本。这一页覆盖模型配置、对话模式、推理强度与上下文管理。

## 模型供应商

在**设置 → 通用 → 供应商**中管理。内置四个预设：

| 供应商 | 默认地址 | 默认 API 路径 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `/chat/completions` |
| Claude | `https://api.anthropic.com/v1` | `/messages` |
| Gemini | `https://generativelanguage.googleapis.com/v1beta` | `/models` |
| DeepSeek | `https://api.deepseek.com/v1` | `/chat/completions` |

每个供应商可配置：

- **名称**：用于在对话中区分不同账号或中转。
- **API 密钥**。
- **API 基础地址**与 **API 路径**：可指向自建网关或兼容端点。
- **模型列表**：点击「获取模型」从 `/models` 拉取，也可以手动添加模型名称。
- **上下文窗口**：可手动填写 token 数或 `128K` / `1M` 形式；留空时按内置预设匹配（例如 `deepseek-v4` 记为 1M、`claude` 记为 200K、`gemini-2` 记为 1M）。

## 对话模式

对话模式**按会话记忆**，新建会话恢复为普通模式。

| 模式 | 说明 |
| --- | --- |
| 普通模式 | 默认。内置工具、MCP 工具与技能都按你在拓展页保存的开关生效。 |
| 计划模式 | 在普通模式的能力基础上，额外注入「计划协议」：AI 会先输出待办计划清单，再逐项执行，完成后对照清单汇报。计划以卡片形式渲染在对话中。 |
| 极简模式 | 只保留终端工具（`run_command`）并强制可用，其余内置工具、MCP 工具与技能全部禁用。适合轻量问答或排查工具干扰。 |

<Callout type="info">
  极简模式不会修改你在拓展页保存的开关状态，切回普通模式后全部恢复。
</Callout>

## 推理强度

推理强度随请求发送给模型：

| 档位 | OpenAI 兼容 | Gemini | Claude |
| --- | --- | --- | --- |
| 关闭 | `reasoning_effort: none` | `thinkingBudget: 0` | 不启用 |
| 自动 | 不发送该字段 | 不发送 | 跟随默认 |
| 低级 | `low` | 1024 | 1024 |
| 中等 | `medium` | 8192 | 4096 |
| 高级 | `high` | 16384 | 8192 |
| 最高 | `xhigh` | 32768 | 16384 |

## 上下文用量

对话界面可以打开**上下文用量**面板，查看本次请求的构成：

- 系统提示词、工具定义、技能、工具调用、对话消息各自占用的 token；
- 输入 / 输出 / 合计与上下文上限占比；
- 缓存命中与未命中、推理 token 消耗；
- 分项明细（按输入折算或本地估算）。

这对判断「是不是工具定义太占上下文」「该不该开极简模式」很有用。

## 附件与输入

- 输入框支持**图片**与**文件**附件；
- 单张图片上限 **5 MB**、最多 **6 张**；单个文件上限 **20 MB**、最多 **6 个**；合计最多 **9 个**；
- 可执行文件与压缩包类扩展名（`apk`、`dex`、`jar`、`so`、`zip`、`exe` 等）被禁止作为附件上传；
- 图片与 PDF 会以 base64 内联发送，其余文本文件读为纯文本拼接；附件内容只存在于内存中，不会写入数据库。
- 支持**语音输入**（需要麦克风权限）。
- 生成过程中可以随时**停止**，已生成的部分会自动保存。

## 工作过程卡片

AI 每一轮的工具调用都会折叠在「工作过程」卡片里，展开可以看到：

- 每一步调用的工具名称（已本地化，例如「反编译类」「搜索字符串」）；
- 调用参数与返回结果；
- 工具输出的完整内容可在**工具输出**编辑器中查看与复制。

## 提问卡片

当 AI 需要你做决定时，会调用 `ask_user` 工具弹出提问卡片：

- 一次可包含 1–5 个问题；
- 每个问题可单选、多选，或自由文本回答；
- 全部回答后统一提交，作为一次工具结果返回给 AI。

## 计划卡片

在计划模式下，AI 会先调用 `todo_write` 提交完整待办清单，之后用 `todo_update` 逐项更新状态。计划卡片实时渲染在对话中，你可以随时看到进度。

## 对话管理

- 会话按目标应用分组保存，可新建、切换、重命名与删除。
- 支持**重试**上一条消息。
- 对话历史保存在本地数据库，可在**设置 → 存储空间 → 聊天记录**中清理。
