先认识界面：导航在哪里、每个页面负责什么、目标应用里会多出哪些入口。

## 导航结构

LSPilot 的底部导航包含三个入口：

| 入口 | 内容 |
| --- | --- |
| 首页 | 模块激活状态、已添加应用数量、已启用数量、已配置的 AI 供应商数量 |
| 项目 | 应用列表与自定义项目分组，进入后是单个应用的详情页 |
| 设置 | 外观、通用、功能拓展、存储空间、实验性功能、关于 |

底栏支持多种样式：图标 + 文字、仅图标、悬浮底栏、玻璃模糊，可在**设置 → 外观**中调整。

## 首页

首页是状态面板，展示：

- **模块激活状态**：显示「已通过 Lsp 102 激活」「已通过 Xp 82 激活」，或未检测到 Xposed 框架。
- **统计卡片**：已添加的应用数、其中已启用的数量、已配置的 AI 供应商数量。
- **常用入口**：直接跳到添加应用、AI 对话或设置。

## 项目

项目页有两个标签：

### 应用

设备上已安装应用的列表，支持按应用名 / 包名 / 安装时间 / 更新时间排序，可隐藏系统应用、按关键字过滤。

点击应用右侧的开关即把它加入 LSPilot 的注入范围（写入 `.enabled` 标记）。点击卡片进入**应用详情页**：

- **插件标签**：该应用的全部插件，含启用开关、编辑、创建、删除；点击可进入日志查看器。
- **分析标签**：启动软件、重启软件、强制停止、动态配置、与宿主进程的重连。
- **注入进程**：主进程 / 子进程 / 所有进程三选一。
- **日志**：查看该应用下所有插件的运行日志与错误日志。

### 自定义

用于不属于已安装应用的场景，例如：

- **导入 APK 安装包**：从文件中选择一个 APK，解析出包名与图标后作为独立项目。
- **创建项目分组**：手动命名一个分组，把分析目标集中管理。

## 设置

| 分组 | 内容 |
| --- | --- |
| 外观 | 主题颜色、配色风格、Monet 动态取色、深浅色模式、页面缩放、底栏样式、悬浮底栏、模糊、液态玻璃、动态背景 |
| 通用 | AI 供应商与模型的配置入口 |
| 功能拓展 | Prompt 拓展、Skills 拓展、MCP 拓展 |
| 存储空间 | 终端环境、聊天记录、APK 缓存、编辑器缓存、其他缓存的占用与清理 |
| 实验性功能 | 尚未稳定的能力，目前主要是性能悬浮窗（需先在首页连点 5 次激活卡开启实验模式） |
| 关于 | 版本信息、项目介绍、特别鸣谢、用户协议、反馈渠道 |

## 目标应用内的入口

模块注入目标应用后会提供悬浮入口（悬浮图标）：

- **UI 检视**：通过 AI 工具 `ui_inspect_on` 或应用详情页开启后，目标应用界面上出现检视触发器，可圈选元素、查看布局树与创建堆栈。
- **性能悬浮窗**：开启后在目标应用上实时显示 FPS / CPU / 内存 / 电池 / 温度等指标，可拖动位置。

<Callout type="info">
  悬浮入口依赖悬浮窗权限；未授权时不会显示，但不影响插件注入与 Hook 生效。
</Callout>

## 文件目录

LSPilot 的运行时数据分布在两处：

```text
/storage/emulated/0/Android/media/<目标应用包名>/LSPilot/   # 目标应用相关
├── .enabled
├── .process_mode
└── Plugin/<插件名>/...

/data/data/me.yun.lspilot/                                  # 模块自身数据
├── files/mcp_plugins/<插件名>/    # MCP 插件
├── databases/                     # AI 对话历史
└── shared_prefs/                  # 设置、MCP 服务器配置、Skills 开关等
```
