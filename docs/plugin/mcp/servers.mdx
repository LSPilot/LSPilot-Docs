把远程 MCP 服务器接入 LSPilot，连接成功后它的工具会自动出现在 AI 的工具列表里。

## 支持的传输方式

| 传输 | 说明 |
| --- | --- |
| Streamable HTTP | MCP 的 HTTP 传输（默认），地址形如 `https://example.com/mcp` |
| SSE | Server-Sent Events 传输，地址形如 `https://example.com/sse` |

<Callout type="warn">
  当前版本**只支持远程 HTTP 类传输**，不支持 stdio。也就是说服务器需要已经运行在某个可访问的地址上（本机服务、局域网主机或公网服务），LSPilot 不会在本机拉起子进程。
</Callout>

## 添加服务器

<Steps>
  <Step>进入**设置 → 功能拓展 → MCP 拓展 → 本地**，点击右下角加号。</Step>
  <Step>填写**服务名称**（同一名称不可重复）。</Step>
  <Step>选择**传输方式**：Streamable HTTP 或 SSE。</Step>
  <Step>填写**服务器地址**，例如 `https://example.com/mcp`。</Step>
  <Step>如有需要，添加**自定义请求头**（例如 `Authorization: Bearer xxx`）。</Step>
  <Step>保存后，在服务器卡片上打开右侧开关开始连接。</Step>
</Steps>

新建的服务器默认是**未启用**状态，需要在卡片上手动打开开关。

## 连接状态

| 状态 | 含义 |
| --- | --- |
| 未启动 | 服务器开关处于关闭状态 |
| 未连接 | 已启用但尚未开始连接 |
| 连接中… | 正在建立连接并拉取工具列表 |
| 已连接 | 连接成功，已发现工具 |
| 连接失败 | 连接出错，可点击「查看错误」查看原因并复制 |

连接成功后工具列表会写回本地配置，因此即使进程重启、或发消息瞬间连接尚未就绪，AI 依然能看到该服务器的工具定义（实际调用仍需要连接在线）。

## 管理工具

点击服务器卡片打开**工具抽屉**：

- 每一行是一个已发现的工具，显示名称、说明与参数摘要；
- 右侧开关控制该工具是否注入 AI；
- 右上角菜单支持**全部开启 / 全部关闭**；
- 每行的**运行**按钮可以手动试运行：无参数工具直接执行，有参数工具会先弹出参数表单；
- 工具的启用状态会在重新连接时保留，不会因为刷新而被重置。

卡片上的徽标显示「启用数/总数」，例如 `3/6`。

## 刷新与重连

- **下拉刷新**：断开并重新连接全部已启用服务器，重新拉取工具列表；
- **重新打开开关**：对单个服务器做一次真实重连；
- 修改了地址或请求头并保存后，LSPilot 会自动强制重连一次，避免继续使用旧连接。

## 删除服务器

长按服务器卡片 → 删除 → 确认。该操作不可撤销。

## 配置保存在哪里

MCP 服务器配置保存在应用私有的 SharedPreferences 中：

```text
/data/data/me.yun.lspilot/shared_prefs/mcp_prefs.xml
```

其中 `mcp_servers` 键保存服务器列表（名称、传输方式、地址、请求头、工具与开关状态）的 JSON。当前版本没有「导入 / 导出 JSON」的界面入口。

## 使用建议

- 请求头里可以放鉴权信息，避免把 Token 写在 URL 上；
- 工具太多会占用上下文预算，用不到的工具建议关掉；
- 在**上下文用量**面板里可以看到工具定义占用的 token 数，工具过多时可考虑改用极简模式或精简开关。
