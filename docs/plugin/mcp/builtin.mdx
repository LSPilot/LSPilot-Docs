内置工具是 LSPilot 自带的 FunctionCall 工具，与 MCP 协议无关，只是放在同一个页面里统一管理。

## 内置工具与 MCP 的关系

「内置」标签下的工具是 LSPilot 自带的 FunctionCall 工具，**与 MCP 协议无关**。它们被放在同一个页面只是为了统一管理。

完整的工具清单见[内置工具](/ref/tools)。

## 分组

工具按功能分为六组，每组的工具互不重叠：

| 分组 | 内容 |
| --- | --- |
| 内置工具 | 终端、文件读写、联网、子任务、提问等通用工具 |
| 静态反编译 | jadx 反编译与 Smali 读取 |
| 动态布局分析 | UI 检视与布局读取 |
| DexKit 搜索 | 类 / 方法 / 字段 / 引用查找 |
| 插件管理 | 插件目录的读写与运行时加载卸载 |
| 技能管理 | Skill 载入与脚本执行 |

## 两级开关

1. **分组总开关**：分类卡片右侧的开关。**分组默认是关闭的**，需要先打开总开关，该组的工具才会生效。
2. **单个工具开关**：点击分类卡片进入工具列表，逐项开关。

工具列表中右上角的**批量操作**可以一次开启或关闭该组的全部工具。

## 试运行

工具列表每行的**运行**按钮可以不经过 AI 直接执行该工具：

- 无参数工具立即执行；
- 有参数工具会弹出表单，按参数类型生成输入框（必填项带星号，枚举类型给出可选项）；
- 结果显示在结果面板中，与 AI 对话中的工具输出使用同一个查看器，支持行号与复制。

<Callout type="info">
  试运行会转发到 `:mcp` 进程执行，与 AI 调用走同一条路径。如果尚未初始化目标应用，会先用 LSPilot 自身作为兜底上下文完成初始化，不会影响当前会话选定的目标应用。
</Callout>

## 上下文占用

内置工具数量较多，工具定义会占用可观的 token。可以：

- 只打开当前需要的分组；
- 在**上下文用量**面板查看「工具定义」分项；
- 需要轻量问答时切换到**极简模式**（只保留 `run_command`）。
