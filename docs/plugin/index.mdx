LSPilot 提供两条扩展路径。它们的运行位置与能力边界完全不同，先分清楚再动手。

| | 项目插件 | MCP 插件 |
| --- | --- | --- |
| 运行位置 | **目标应用进程**内 | **LSPilot 进程**内 |
| 用来做什么 | Hook 目标应用、改参数、改返回值 | 给 AI 提供工具 |
| 入口文件 | `main.java`（BeanShell） | `main.java`（BeanShell） |
| 存放位置 | `Android/media/<包名>/LSPilot/Plugin/` | 应用私有目录 `files/mcp_plugins/` |
| 生效方式 | 强制停止并重启目标应用 | 工具抽屉「重新加载」 |
| AI 侧函数名 | — | `plugin__<插件>__<工具>` |

如果目标是「让 AI 按我固定的套路去分析」，写 **MCP 插件**；如果目标是「改变目标应用的行为」，写 **项目插件**。
